# Package index

## Building a plot

Start a plot, then add layers, labels and options with `+`.

- [`orb()`](https://mqfarooqi1.github.io/orbis/reference/orb.md) : Start
  a plot
- [`` `+`( ``*`<orb_spec>`*`)`](https://mqfarooqi1.github.io/orbis/reference/plus-.orb_spec.md)
  : Add layers, scales, labels and themes to a plot
- [`orb_labs()`](https://mqfarooqi1.github.io/orbis/reference/orb_labs.md)
  : Axis, legend and plot labels
- [`orb_options()`](https://mqfarooqi1.github.io/orbis/reference/orb_options.md)
  : Plot-level options

## Layers

Geometries drawn from the data.

- [`orb_points()`](https://mqfarooqi1.github.io/orbis/reference/orb_points.md)
  : Point layer
- [`orb_line()`](https://mqfarooqi1.github.io/orbis/reference/orb_line.md)
  : Line layer
- [`orb_bars()`](https://mqfarooqi1.github.io/orbis/reference/orb_bars.md)
  : Bar layer
- [`orb_area()`](https://mqfarooqi1.github.io/orbis/reference/orb_area.md)
  : Area layer
- [`orb_text()`](https://mqfarooqi1.github.io/orbis/reference/orb_text.md)
  : Text layer

## Maps and projections

Geographic layers and coordinate systems, including an orthographic
globe.

- [`orb_map()`](https://mqfarooqi1.github.io/orbis/reference/orb_map.md)
  : World map layer
- [`orb_geo_points()`](https://mqfarooqi1.github.io/orbis/reference/orb_geo_points.md)
  : Point layer positioned by longitude and latitude
- [`orb_worldmap()`](https://mqfarooqi1.github.io/orbis/reference/orb_worldmap.md)
  : A ready-made world map
- [`orb_coord_map()`](https://mqfarooqi1.github.io/orbis/reference/orb_coord_map.md)
  : Map projections
- [`orb_coord_cartesian()`](https://mqfarooqi1.github.io/orbis/reference/orb_coord_cartesian.md)
  : Cartesian coordinates
- [`world_map`](https://mqfarooqi1.github.io/orbis/reference/world_map.md)
  : World country polygons

## Output

Interactive SVG, or publication-quality raster and vector output.

- [`orb_save()`](https://mqfarooqi1.github.io/orbis/reference/orb_save.md)
  : Save a plot at any resolution
- [`orb_svg()`](https://mqfarooqi1.github.io/orbis/reference/orb_svg.md)
  : Render a plot as SVG
- [`orb_interactive()`](https://mqfarooqi1.github.io/orbis/reference/orb_interactive.md)
  : Open or write an interactive plot
- [`orb_draw()`](https://mqfarooqi1.github.io/orbis/reference/orb_draw.md)
  : Draw a plot on the current graphics device
